USAGE NOTES
-----------
- Use #4fd1c7 and #81c784 for primary navigation and headers
- Use #e0f2f1 and #f1f8e9 for main backgrounds
- Use #2e7d6b for body text and icons
- Use rgba(255,255,255,0.9) for button backgrounds
- Apply gradients to game tiles and interactive elements
- Use shadows for depth: 0 5px 15px rgba(0,0,0,0.1) for subtle lift
- Maintain white text on colored backgrounds for contrast
